# 한마음제자교회 주보

휴대폰에서 바로 여는 주일 주보입니다. 카카오톡 링크로 보고, 필요하면 A4로 인쇄합니다.

## 매주 업데이트하는 방법
1. `data/` 폴더에서 지난주 파일(예: `2026-10-04.js`)을 복사해 새 날짜로 이름을 바꿉니다 (예: `2026-10-18.js`).
2. 새 파일을 열어 날짜(`date`), 호수(`issue`), 찬양(`praise`), 예배순서(`order`: 설교·성경봉독·기도자 등), 교회 소식(`news`), 예배위원(`servers`), 새가족(`newcomers`), 헌금자(`offerings`, `youth`)를 고칩니다.
   - `[설교 제목]`처럼 대괄호 안을 붙여 쓴 자리표시는 화면에 칠해져 보입니다. `[ 새 가족 환영 ]`처럼 대괄호 안을 띄어 쓴 글은 본문으로 둡니다.
   - `stand: true` → 순서 앞에 ※ (일어섬), `song: true` → ♬.
3. `data/current.js`에서 `JUBO_CURRENT`를 새 날짜로 바꾸고, `JUBO_WEEKS` 목록 맨 앞에 추가합니다.
4. GitHub에 커밋하면 1~2분 뒤 홈페이지에 반영됩니다. 다른 주 보기: `?week=2026-10-11`.

데이터 항목은 이전과 같습니다. 화면 배치만 모바일 주보로 바뀌었습니다.

## 인쇄 / PDF
- 화면 위의 **인쇄 / PDF** 버튼(좁은 화면에서는 **인쇄**) → 용지 A4, 여백 기본, "배경 그래픽" 켜기.
- 명령줄: `./render.sh 2026-10-11` → `preview/` 에 PDF·PNG 생성.

## 고정 정보 · 로고
- 교회 비전, 주중 모임, 예배시간, 주소, 표어: `data/church.js`
- 로고: `assets/logo.png` 파일만 바꾸면 됩니다 (정사각형 PNG 권장). 화면에서는 작게 쓰입니다.
- 오시는 길: 약도를 따로 그리지 않습니다. `church.js`의 주소로 구글 지도를 엽니다.
